## 0. 한눈에: 왜 이 가이드가 필요한가

문제 이름은 최소 타일 집합 문제(Minimum Tileset Problem)다.
일반 모양은 어렵다고 알려져 있다.
2×n 직사각형만 따로 보면 답이 어디까지 알려졌는지 먼저 알아야 한다.

| 칸 | 내용 |
| --- | --- |
| 풀려던 문제 | 2×n 직사각형의 복잡도를 모른다. 시드(seed)가 모서리일 때만 식이 있어 보인다 |
| 결과·목적 | 알려진 상한과 하한을 정리하고, 시드가 모서리가 아닌 경우의 열린 문제에 쓸 결과를 고른다 |
| 임무(mission) | 2쪽 논문에 증명된 결과와 미확인 결과를 구분해 쓴다 |
| 비전(vision) | 2×n 직사각형 문제의 복잡도를 한 걸음 더 밝힌다 |

전체 흐름은 다음과 같다.

```
모양 2×n (입력)
      |
      v
추상 타일 조립 모델(aTAM)에서 지시 조립으로 만들 최소 타일 종류 수 t
      |
      +-- 하한: t ≥ √n / 2        (시드 위치 무관, 증명됨)
      |
      +-- 상한: t ≤ 4⌈√n⌉ + 2     (온도 2, 모서리 시드, 증명됨)
      |
      v
정확한 값은?
   |                    |
 시드가 모서리         시드가 모서리가 아님
 (식이 있어 보임)       (열린 문제)
```

각 상자의 용어는 문서 끝 [용어 부록](#용어-부록-terms-appendix)에 있다.

## 1. 문제를 한 줄로

모양 하나가 입력으로 주어진다.
그 모양을 [지시 조립(directed self-assembly)](#term-directed)으로 만드는 최소 [타일 종류(tile type)](#term-tile-type) 수를 구한다.
모양이 2×n 직사각형일 때 이 문제의 복잡도를 묻는다.

문제 원문의 힌트는 둘이다.
- [시드(seed)](#term-seed)가 모서리에 있어야 한다면, 식과 [다항 시간(polynomial time)](#term-poly) 알고리즘이 있어 보인다.
- 그 가정이 없으면 문제는 열려 있다.

원문 진술은 `uniquely self-assemble`이다.
표준 뜻으로 읽으면 이것은 [지시 조립(directed self-assembly)](#term-directed)이다 (추정).
출제자에게 확인할 질문이다 (`03_plan_and_design.md`의 질문 목록).

| --- | --- | --- | --- |
| 1 | [추상 타일 조립 모델(abstract Tile Assembly Model, aTAM)](#term-atam)과 [타일 종류(tile type)](#term-tile-type). 사각형 한 칸, 네 변 N, E, S, W마다 [접착 라벨(glue label)](#term-glue). 타일은 회전하지 않고 평행이동만 한다 | 문제 전체의 언어다 | 타일 종류를 네 접착 라벨의 순서쌍으로 쓸 수 있는가 |

| 5 | [시드(seed)](#term-seed), [생성 가능 조립체(producible assembly)](#term-producible), [종단 조립체(terminal assembly)](#term-terminal) | "만든다"의 정의다 | 종단 조립체가 왜 더 못 자라는지 말할 수 있는가 |
| 6 | [지시 조립(directed self-assembly)](#term-directed) 대 [엄격 조립(strict self-assembly)](#term-strict) | 같은 문제의 두 판이 있다 | 두 정의의 차이를 한 줄로 쓸 수 있는가 |
| 7 | [빗 구성(comb construction)](#term-comb) | 모든 온도와 시드 위치에 맞는 상한 n + 1을 준다 | n = 3일 때 타일 종류 4개를 그릴 수 있는가 |
| 8 | [카운터(counter)](#term-counter), k자리 m진수 | 상한 4⌈√n⌉ + 2의 뼈대다 | 높이 2에서 왜 이진 카운터가 안 맞는지 설명할 수 있는가 |
| 9 | [하한(lower bound)](#term-lower-bound)의 [세기 논증(counting argument)](#term-counting)과 [펌핑(pumping)](#term-pumping) | 하한 √n / 2의 근거다 | 세로 절단선이 타일 두 개만 지나는 이유를 아는가 |

지시 조립과 엄격 조립의 정의는 다음과 같다.

```
지시 조립: 종단 조립체가 정확히 하나, 모양이 S
           어느 실행에서나 같은 자리에 같은 타일 종류
엄격 조립: 모든 종단 조립체의 모양이 S
           실행마다 같은 자리에 다른 타일 종류가 올 수 있음
```

빗 구성(F3, 손 유도)은 다음과 같다.

```
위 줄    T  T  T  T  T      T: 위 타일 하나, 남쪽 접착 u
아래 줄  B1 B2 B3 B4 B5     B1이 시드 (왼쪽 아래 모서리)
         → 아래 줄은 동쪽 접착 e_i가 세기 τ, 모든 B_i는 북쪽 접착 u가 세기 τ
타일 종류 수 = n + 1
```

높이 2 카운터의 숫자는 다음과 같다.

```
상한 (온도 2, 모서리 시드):  t ≤ 4⌈√n⌉ + 2
예 n = 100:    5 ≤ t ≤ 42
예 n = 10,000: 50 ≤ t ≤ 402
```

- Furcy, Summers, Wendlandt. *New bounds on the tile complexity of thin rectangles at temperature-1*. arXiv 1808.04358 [S-MTS-5].
- Bryans, Chiniforooshan, Doty, Kari, Seki. *The power of nondeterminism in self-assembly*. SODA 2011 [S-MTS-3].
- Chen, Doty, Seki. *Program size and temperature in self-assembly*. arXiv 1011.3493 [S-MTS-4].
- Mahaney (1982), 희소 NP-완전 집합 정리 [S-MTS-7]. 읽은 범위: 위키백과와 검색 요약만.

## 3. 가장 중요한 통찰 (먼저 이해할 것)

### 3.1 높이 2는 정보를 타일 두 개로만 나른다

왜 중요한가. 하한 √n / 2가 이 한 문장에서 나온다.

2×n 띠를 세로로 자르면 절단선은 타일 두 개만 지난다.
그래서 서쪽과 동쪽 사이의 정보는 세 가지뿐이다.
- 위 타일 종류
- 아래 타일 종류
- 붙은 순서 (위가 먼저인가, 아래가 먼저인가)

```
  서쪽   | 절단선 |   동쪽
  ... [위]  |  [위] ...
  ... [아래]|  [아래] ...
        한 쌍(위, 아래) + 순서 → 상태(state)
```

타일 종류가 t개면 이런 [열 상태(column state)](#term-column-state)는 최대 약 2·t²개다 (손 유도, 직관).
같은 상태가 시드의 같은 쪽에서 반복되면 그 사이를 [펌핑(pumping)](#term-pumping)할 수 있다.
그러면 모양이 무한해진다.
그래서 한쪽에 서로 다른 열은 약 2·t²개 미만이다.
이로부터 n ≲ 4·t²가 나온다.
정확한 반복 횟수는 [S-MTS-2]에 있다.

증명된 하한의 정확한 형태는 다음과 같다 ([S-MTS-2] 정리 3.1의 증명, k = 2).

```
t < (n / (2·2!))^{1/2} 이면 2×n을 지시 조립으로 못 만든다
따라서 t ≥ √n / 2
```

- 시드가 어디에 있어도 성립한다. 증명이 "시드 위치와 무관"하다고 명시한다.
- 높이 k ≤ 2인 길이 n 모양 어디에나 쓸 수 있다는 주석이 증명 뒤에 있다.

### 3.2 온도 2에서는 높이 2라도 카운터가 들어간다

왜 중요한가. 상한이 n + 1에서 약 √n으로 내려온다.

| 사실 | 상태 | 출처 |
| --- | --- | --- |
| 높이 2에 k = 2자리 m진수 카운터가 들어간다. m = ⌈√n⌉, 타일 종류 4m + 2개, 온도 2, 모서리 시드 | 증명됨 (PROVEN) | [S-MTS-2] 정리 3.2 |
| 길이 n은 서쪽 접착의 시작값 m^k − N으로 조절한다. 1..m^k 중 어떤 길이도 가능하다 | 증명됨 (PROVEN) | [S-MTS-2] 8쪽 |
| log n 비트 이진 카운터는 높이 2에 안 들어간다 | 증명됨 (하한 √n / 2에서 따라옴) | [S-MTS-2] |

결론은 온도 2에서 2×n의 답이 Θ(√n)이라는 것이다.
상수 차이는 약 8이다 (추정).

### 3.3 시드 위치가 문제를 가른다

왜 중요한가. 열린 부분이 정확히 여기다.

| 시드 | 상태 | 이유 |
| --- | --- | --- |
| 모서리 | 식이 있어 보인다 (출제자 진술). 정확한 식은 자료에서 못 찾았다 | 한쪽으로만 자란다 |
| 안쪽 칸 | 열림 | 서쪽과 동쪽 두 팔이 자란다 |

안쪽 시드에서 달라지는 점은 다음과 같다 (추정).
- 하한 √n / 2는 그대로 성립한다.
- 두 팔에 카운터를 따로 쓰면 모서리보다 비싸다.
- 두 팔이 타일 종류를 **공유**해야 이긴다.
- 타일은 회전하지 않는다. 서쪽으로 자라는 타일과 동쪽으로 자라는 타일은 접착이 두 방향에 모두 맞아야 공유한다.
- 이것이 이 문제의 핵심 어려움이다.

### 3.4 온도 1은 거의 다 열려 있다

| 설정 | 하한 | 상한 | 상태 |
| --- | --- | --- | --- |
| 결합 불일치(binding-domain mismatch) 없음 가정 | n + 1 | n + 1 | 조건부 증명. 요약문만 읽음 |
| 가정 없음 (2차원) | Ω(√n) | n + 1 | 정확한 값은 찾지 못함 |

- 조건부 결과는 [S-MTS-6]이고 부분 확인이다. [맨해튼 지름(Manhattan diameter)](#term-manhattan)의 정의를 전문에서 확인하지 못했다.
- 가정 없는 범위는 [S-MTS-5]의 Ω(N^{1/k})와 N + k − 1에서 k = 2로 얻는다.
- 우리가 받은 직관은 "온도 1에서는 2×n의 한 줄이 같은 타일 종류를 반복하면 펌핑이 생긴다"였다. 가정 아래서만 증명되어 있다. 2차원 일반 경우는 [S-MTS-5]도 격차를 명시한다.

## 4. 학습 순서 체크리스트

- [ ] 정리 3.2의 타일 묶음 그림 3.1을 따라 그린다. 시드 열이 동쪽 끝 모서리에 있다.
- [ ] 안쪽 시드에서 두 팔이 타일 종류를 공유하는 예를 하나 만들어 본다 (3.3).
- [ ] 계산이 필요한 항목을 표로 정리한다. 실행은 클러스터에서 한다 (6장).

```
2×1 → 빗 구성 → 하한 √n/2 → 카운터 상한 → 안쪽 시드 (열림)
(쉬움)                                          (어려움)
```

## 5. 함정 (Pitfalls)

1. **모델이 모호하다.** 온도 τ가 1인지 2인지, 풀이자가 고르는지 문제에 없다. 결과가 온도마다 다르다. [온도(temperature, τ)](#term-temperature)를 논문에 명시해줘.
2. **지시 조립인지 엄격 조립인지 모호하다.** Adleman 등 2002는 지시 조립을 쓴다. Bryans 등은 엄격 조립을 쓰고, 그 문제는 [Σ2^P-완전(Σ2^P-complete)](#term-sigma2)이다. 판마다 다른 정리를 쓴다.
3. **입력 인코딩이 모호하다.** 모양을 칸 목록으로 주면 입력 크기가 Θ(n)이다. n을 이진수로 주면 크기가 log n이다. 희소성 논증(`02_possible_solutions.md`의 방향 1)은 칸 목록에서만 성립한다.
4. **"시드가 모서리"의 뜻이 모호하다.** 네 모서리 중 어느 것도 되는지 불분명하다. 이 점을 질문으로 넘긴다.
5. **하한 √n / 2는 시드 위치와 무관하다.** 상한은 모서리 시드를 쓴다. 두 값을 섞어 "시드 위치에 따른 정확한 값"이라고 쓰지 마.
6. **손으로 만든 카운터는 검증 전이다.** 자료의 약 m + 3D + 2개 타일 종류 구성은 시뮬레이션을 하지 않았다. 증명된 것처럼 쓰지 마. 논문에는 "미확인"으로 쓰거나 R2 결과를 기다려줘.
7. **정확한 모서리 시드 공식은 못 찾았다.** 출제자 진술에 식이 있다고만 나온다. 자료에서 공식을 찾지 못했다. 식을 지어내지 마.
8. **출제자 신원은 추정이다.** "Dr. Schwaller"가 UTRGV의 Robert Schweller인지 확인하지 못했다. 논문에 이름을 단정해 쓰지 마.
9. **읽지 못한 자료가 있다.** [S-MTS-8], [S-MTS-9]의 저자와 결과는 미확인이다. 인용하지 마.

## 6. 계산 작업에 관한 주의 (이 머신 규칙)

왜 막는가. 이 머신에서 계산을 돌리면 CPU를 오래 점유한다. 규칙은 `~/.claude/CLAUDE.md`에 있다.

```
로컬 금지                        로컬 허용
-----------------------------    -----------------------------
타일 집합 전수 탐색(R1)          저장된 결과로 그림과 표 그리기
카운터 시뮬레이션(R2)
```

- [전수 탐색(brute-force search)](#term-brute-force)과 시뮬레이션은 로컬에서 바로 실행하지 않는다.
- R1: 2×n, n = 2..8, 온도 1과 2, 시드 위치마다 최소 타일 종류 수를 찾는다.
- R2: 손으로 만든 카운터를 몇 개의 (m, D)로 시뮬레이션한다.
- 둘 다 클러스터에서 한다. 제출은 메인 세션만 한다.
- 프로젝트 루트 `CLAUDE.md`에 계산 환경이 아직 없으면, 먼저 어떤 클러스터나 Colab을 쓸지 정해줘.
- 저장된 결과로 그림을 그리는 작업은 로컬에서 해도 된다.

## 용어 부록 (terms appendix)

<a id="term-atam"></a>
- **추상 타일 조립 모델(abstract Tile Assembly Model, aTAM)**: 사각형 타일이 격자 위에서 한 장씩 붙으며 모양을 만드는 수학 모델.

<a id="term-tile-type"></a>
- **타일 종류(tile type)**: 네 변(N, E, S, W)에 접착 라벨이 하나씩 붙은 사각형 한 종류. 같은 종류의 타일은 얼마든지 쓴다.

<a id="term-glue"></a>
- **접착 라벨(glue label)**: 타일 변에 붙은 이름. 마주 본 변의 라벨이 같아야 접착이 생긴다.

<a id="term-strength"></a>
- **접착 세기(glue strength)**: 접착 라벨마다 정한 0, 1, 2, ... 중 하나의 수. 양수여야 붙는다.

<a id="term-temperature"></a>
- **온도(temperature, τ)**: 타일이 붙기 위해 필요한 접착 세기의 합의 문턱값.

<a id="term-cooperation"></a>
- **협력 결합(cooperative binding)**: 온도 2에서 세기 2 접착 하나, 또는 세기 1 접착 둘이 함께 타일을 붙이는 일.

<a id="term-seed"></a>
- **시드(seed)**: 정해진 자리에 놓인 첫 타일. 모든 성장이 여기서 시작한다.

<a id="term-producible"></a>
- **생성 가능 조립체(producible assembly)**: 시드에서 시작해 세기 τ 이상으로 타일을 한 장씩 붙여 도달하는 조립체.

<a id="term-terminal"></a>
- **종단 조립체(terminal assembly)**: 더 이상 타일이 붙을 수 없는 생성 가능 조립체.

<a id="term-directed"></a>
- **지시 조립(directed self-assembly)**: 종단 조립체가 정확히 하나이고 그 모양이 목표 모양인 경우. 어느 실행에서나 같은 자리에 같은 타일 종류가 온다.

<a id="term-strict"></a>
- **엄격 조립(strict self-assembly)**: 모든 종단 조립체의 모양이 목표 모양인 경우. 실행마다 타일 종류가 달라도 된다.

<a id="term-comb"></a>
- **빗 구성(comb construction)**: 아래 줄에 서로 다른 타일 n개, 위 줄에 같은 타일 하나를 쓰는 n + 1종 구성.

<a id="term-counter"></a>
- **카운터(counter)**: 열을 지날 때마다 수를 세어 길이를 정하는 타일 구성.

<a id="term-lower-bound"></a>
- **하한(lower bound)**: 어떤 구성도 이보다 적은 타일 종류로는 안 된다는 증명된 값.

<a id="term-counting"></a>
- **세기 논증(counting argument)**: 가능한 상태의 수를 세어 한계를 보이는 증명 방법.

<a id="term-pumping"></a>
- **펌핑(pumping)**: 반복되는 상태 사이의 조각을 되풀이해 모양을 무한히 늘리는 논증.

<a id="term-column-state"></a>
- **열 상태(column state)**: 한 세로 절단선이 지나는 위, 아래 타일 종류와 붙은 순서의 묶음.

<a id="term-manhattan"></a>
- **맨해튼 지름(Manhattan diameter)**: 모양 안 두 칸 사이 격자 거리의 최댓값. 이 자료에서 정의는 전문 확인 전이다.

<a id="term-sigma2"></a>
- **Σ2^P-완전(Σ2^P-complete)**: NP보다 한 층 위의 계산 복잡도 부류에서 가장 어려운 문제군.

<a id="term-poly"></a>
- **다항 시간(polynomial time)**: 입력 크기의 다항식으로 늘어나는 계산 시간.

<a id="term-brute-force"></a>
- **전수 탐색(brute-force search)**: 가능한 후보를 모두 만들어 하나씩 검사하는 방법.
