Minimum Tileset for a 2×n Rectangle: Study Tips

This is a study map for beginners. You learn what to know and why, step by step. Each tab leads through numbered step boxes.

The problem is this. You get one shape. You find the fewest tile types that assemble that shape uniquely. This page covers the case where the shape is a 2×n rectangle.

Step 5 of 8

Intuition for the bound √n / 2: a repeated state lets us lengthen the shape

Result. With few tile types t, the column states run out and some column repeats. The state also includes the attachment order. Then pumping makes the shape infinitely long, which is a contradiction.

  • At τ = 2, matching glues alone do not allow the copy.

Step 1 of 6

Problem and key idea: how many tile types build this shape

Result. With temperature (τ) = 2 and the seed in a corner, the minimum number of tile types for 2×n is Θ(√n). We did not find the exact formula. With an interior seed, even the setter says it is open. We know only the order Θ(√n) (the upper bound is by hand).

Basis: lower bound √n / 2 (PROVEN), upper bound 4⌈√n⌉ + 2 (PROVEN). Both come from Aggarwal et al. 2005 (S-MTS-2). Step 3 plots them.

Problem to solve. We do not know how few tile types can build one shape. Fewer types give a smaller assembly design. We call this number the tile complexity.

The abstract Tile Assembly Model (aTAM) on one page

Tiles only translate. They do not rotate. This rule is an inference from the definition and is PARTIAL. The problem statement says "uniquely self-assemble". We read it in the standard way as directed self-assembly (inference). Step 6 asks the setter to confirm.

Why 2×n is a problem

  • We look at the Minimum Tileset Problem for general shapes.
  • This problem is nondeterministic polynomial-time complete (NP-complete) (Adleman et al. 2002).
  • An N×N square is solvable in polynomial time.
  • We found no exact complexity result for the 2×n rectangle (open as far as found).
  • The problem statement: if the seed must sit in a corner, a formula seems to exist. Without that assumption the case is open.

Step 5 of 6

Research directions for the open case

Problem to solve. We must write a 2-page paper in 24 hours. We rank what we can claim in the open interior-seed case. We also rank the risks.

The key fork

  • If the seed sits in column s (1 < s < n), growth goes along two arms, west and east. Their lengths are s − 1 and n − s.
  • The lower bound √n / 2 still holds. Theorem 3.1 does not depend on the seed position.
  • Separate counters on the two arms cost c√a + c√b (a + b = n − 1). This is more than the c√n of the corner seed (inference). The upper bound 4√2·√n + O(1) still gives order Θ(√n) (by hand).
  • An interior seed wins only if the two arms share tile types. Tiles do not rotate. So the west-growth glue and the east-growth glue must both fit in one type.

A realistic 24-hour paper (inference from the note)

  1. State rank 1 and rank 2 as theorems.
  2. State the 8x form of rank 5 as a theorem, using [S-MTS-2] alone. Add the 7x form if the hand-derived counter is verified.
  3. State rank 3 as a conjecture. Add the rank 6 data as evidence if we have it.

Study tips and plan

Problem to solve. Time to the deadline is short. You save time if you know what to learn first and where mistakes are likely.

Basics to learn first

  1. The rules of tile type, glue, temperature (τ), and cooperative binding
  2. Producible assemblies and terminal assemblies
  3. The difference between directed self-assembly and strict self-assembly
  4. Write by hand why one tile type fails for 2×1 (F1)
  5. Check the comb upper bound n + 1 yourself (F3)
  6. The lower-bound argument: a column holds only 2 tiles, so there are at most 2t² states. A state that repeats with the same attach order allows pumping (DERIVED-BY-HAND)
  7. Read the counter construction of Aggarwal et al. (Figure 3.1, Theorem 3.2)
  8. Big-O, Omega, and Theta notation, and sparse sets

Study order

  1. Summarize the problem statement and the abstract Tile Assembly Model (aTAM) definition in one page
  2. Click n = 1 ... 8 in the Step 2 view and follow the same assembly by hand
  3. Prove F1 and F3 in 5 lines each
  4. Put k = 2 into Aggarwal et al. Theorem 3.1 to get √n / 2
  5. Pick an empty cell on the Step 4 map
  6. Draft the proofs for rank 1 and rank 2 of Step 5. Write the encoding assumption first
  7. Finish the paper skeleton even without R1 and R2 results

Pitfalls

  • Mixed-up definitions. Directed self-assembly and strict self-assembly differ. Adleman et al. treat the first. Bryans et al. treat the second.
  • Temperature. τ = 1 and τ = 2 give different answers. Check whether τ is fixed or chosen by the solver.
  • Encoding. Rank 1 holds only for unary n or a sorted cell list. It breaks if n is given in binary.
  • Unverified sources. Check the original of S-MTS-8, 9, 11, 12 before you cite them.
  • Hand-derived counter. Do not use it as a theorem before simulation. Use it as a candidate.
  • n + 1 at τ = 1. It is proven only under the no-glue-mismatch assumption.
  • The setter's name. That Dr. Schwaller is Robert Schweller is an assumption.

We do not run the search on this computer. We run it on the cluster.

Step 1 of 3

What this problem is

Problem to solve. You cannot find the literature for a problem that has no name. A name links it to earlier work.

This problem is the 2×n rectangle case of the Minimum Tileset Problem. The 2×n rectangle is the case k = 2 of the more general thin rectangle k×N.

As an assembly

Start from one seed and attach only tiles whose glues match. It succeeds if there is exactly one terminal assembly and its shape is 2×n.

As complexity

The general shape case is nondeterministic polynomial-time complete (NP-complete). The square case is polynomial time. We did not find the exact complexity of 2×n.

As a design

The task is to fit a counter that counts the length n into height 2. At height 2 a binary counter does not fit. A 2-digit counter with base about √n fits.

The square algorithm is an exhaustive search. It tests every τ = 2 system with at most O(log n / log log n) tile types. The input is a cell list, so its size is about n².

Step 3 of 4

Where this problem sits

Problem to solve. We need to know what is new at the hackathon. Splitting the known from the gaps shows the contribution.

Already known

  • General shapes are nondeterministic polynomial-time complete (NP-complete).
  • Trees and squares take polynomial time.
  • Bounds for k×N thin rectangles: lower bound Ω(N1/k/k) and upper bound O(N1/k + k) (τ = 2).
  • The lower bound holds wherever the seed is.
  • At τ = 1 we have Ω(N1/k) ≤ t ≤ N + k − 1.

Gaps this hackathon can fill

  • The exact formula for the corner seed at τ = 2 (the formula the problem statement says exists)
  • The complexity and upper bound for the interior seed
  • The exact value at τ = 1 (without the assumption)
  • An exact complexity result for 2×n: we did not find one.
