## 2. 2차 수정에서 새로 들어온 수학

### 2.1 희소 집합 인코딩

판정: 수학은 맞다. NEW ERROR 1건(문구).

- 정규형: ⟨1^n, s, k⟩, s와 k는 단항(또는 폭 ⌈log₂(2n + 2)⌉ 고정), k ≥ n + 1은 고정된 예 입력으로 보낸다.
- 희소성: 단항이면 길이 L인 문자열은 n + s + k ≤ L인 세 수로 정해진다. 개수는 O(L²)다(시드 자유 판은 O(L)). 고정 폭이면 n마다 O(n) × O(n)개다. 둘 다 다항식이다. 희소하다.
- k 상한이 필요한 이유: 상한이 없고 k가 이진수면 n = 1에 ℓ비트 k가 약 2^ℓ개다. 노트의 설명이 맞다.
- 비결정 다항 시간(NP) 소속, τ 고정: 증거는 k ≤ n종의 타일 집합이다. 글루 라벨 O(k)개, 세기 ≤ τ로 크기는 poly(n)이다. 검증은 [S-MTS-1]의 다항 시간 유일 생성 검사다. k ≥ n + 1은 빗(F3)으로 언제나 예다. 맞다.
- 환원 방향: 원래 문제 ≤ 정규형. 원래 문제가 NP-완전이면 정규형은 NP-어려움이고 NP에 속하므로 NP-완전이다. 희소하므로 Mahaney로 P = NP. 맞다.
- 직사각형이 아닌 입력 → 고정된 아니오 입력: 맞다.

NEW ERROR (문구, 정리가 실제보다 약하게 쓰임).
- `03_plan_and_design.md` 44행: "이진수 n과 이진수 k에서는 실패한다."
- `study_tips.html` 1041행 위험 칸: "n이나 k를 이진수로 주면 희소하지 않아 논증이 깨집니다."
- 틀린 이유: 입력의 k가 이진수여도 논증은 성립한다. 환원이 k를 n + 1과 비교하고(다항 시간), 단항이나 고정 폭으로 다시 쓴다. 정규형은 그대로 희소하다.
- 실패하는 것은 "이진수 n"뿐이다. 그리고 "상한 없는 이진수 k를 정규형에 쓰는 것"이다. 노트와 `02`는 이 뜻으로 쓰여 있어 맞다.

### 2.3 안쪽 시드 상한 O(√n): 두 팔 카운터, 4√2·√n + O(1)

판정: 맞다. 상수 4√2도 맞다.
- 서쪽 팔 a = s − 1열, 동쪽 팔 b = n − s열, a + b = n − 1.
- 팔 하나: [S-MTS-2] 정리 3.2, k = 2. 시드 열 포함 a + 1열이면 m = ⌈√(a + 1)⌉ ≤ ⌈√a⌉ + 1이다. 비시드 타일 4m종. 차이는 O(1)에 들어간다.
- 동쪽 팔: 좌우 거울상. aTAM 규칙은 좌우 반사에 대칭이다. 라벨은 서쪽 팔과 겹치지 않게 새로 쓴다.
- 시드 열: 두 타일이 서쪽 팔의 W 글루와 동쪽 팔의 E 글루를 함께 가진다. N/S 글루는 하나다. 상수 개.
- 서로 간섭 없음: 서쪽 팔 타일이 시드 열 동쪽에 붙으려면 시드 열의 E 글루가 필요하다. 그 라벨은 동쪽 팔 전용이다. 반대도 같다.
- 합: 4⌈√a⌉ + 4⌈√b⌉ + O(1) ≤ 4(√a + √b) + O(1).
- √a + √b ≤ √(2(a + b)) (코시-슈바르츠(Cauchy–Schwarz), 등호 a = b).
- 따라서 ≤ 4√2·√(n − 1) + O(1) ≤ 4√2·√n + O(1). 4√2 ≈ 5.66.
- 위 행 시드 칸: 위아래도 뒤집는다(F7). a = 0이면 모서리 경우와 같다.
- 의존: 팔 길이 1..m² 모두 가능하다는 [S-MTS-2] 8쪽 주장. 모든 파일이 "손 유도, 8쪽 길이 주장에 기댐"으로 표시한다. 맞다.

### 2.4 상수 1/2 문구, 영화 수 ≤ 2t(t + 1)

판정: 맞다.
- 높이 2의 창(window)은 변 2개다. 한 변을 지나는 결합의 라벨은 서쪽 타일의 E 글루로 정해진다. 그래서 t가지 이하다.
- 조립체는 연결되어 있으므로 창마다 결합이 1개 이상이다. 빈 영화는 없다.
- 영화 수: 결합 1개(자리 2 × 라벨 t) + 결합 2개(순서 2 × 라벨 t²) = 2t² + 2t = 2t(t + 1).
- 시드 한쪽의 창은 (n − 1)/2개 이상이다. 영화가 모두 다르면 (n − 1)/2 ≤ 2t(t + 1)이다.
- 곧 n ≤ 4t(t + 1) + 1, t ≥ (√n − 1)/2 정도. "약 √n/2"가 맞다.
- 열 상태 셈(≤ 2t²)은 n ≤ 4t² + 1, t ≥ √((n − 1)/4)를 준다. 노트 125행, 가이드 163–164행과 같다.
- "느슨한 셈 → 약 √n/4": 참인 더 약한 상한이다. "WML이 주는 값"이라는 옛 단정은 사라졌다.

### 2.5 2^{O(√n log n)} 탐색, 고정 시드 칸

판정: 맞다(노트, `02`, `03`). HTML 표 5는 누락(F6).
- t_max: 시드 자유 또는 모서리 시드는 4⌈√n⌉ + 2(증명됨). 고정 시드 칸은 4⌈√a⌉ + 4⌈√b⌉ + O(1) = O(√n)(손 유도).
- 후보 수: 변 4개 × 라벨 ≤ 4t + 1개, 세기 ≤ τ = 2. (O(t))^{4t} = 2^{O(√n log n)}.
- 곱하기: 시드 칸 2n개(시드 자유일 때)와 시드 종류 t개. 검사는 각각 poly(n).
- 탐색 상한이 증명된 OPT 상한 이상이어야 정확하다. 고정 안쪽 시드에 4⌈√n⌉ + 2를 쓰면 이 조건이 증명되지 않는다. 노트, `02`, `03`은 두 팔 상한으로 고쳤다.
- τ = 1: 상한 n + 1뿐이라 2^{O(n log n)}. 이진수 n: 입력 길이 log n이라 부분지수가 아니다. 맞다.

### 2.6 "약 29배" = 10,036 / 349

판정: 맞다.
- n = 1 + 173 · 58 = 1 + 10,034 = 10,035.
- 카운터: 173 + 3 · 58 + 2 = 173 + 174 + 2 = 349.
- 빗: 10,035 + 1 = 10,036.
- 349 × 28 = 9,772, 349 × 29 = 10,121. 10,036 / 349 = 28.76. HTML의 "28.8, 약 29배"가 맞다.
- 함께 확인: 4⌈√10,035⌉ + 2 = 4 · 101 + 2 = 406 (그림 9). √10,035 / 2 = 50.09 (그림 9의 50.1). n = 49: 4 · 7 + 2 = 30, √49 / 2 = 3.5, 26 / 50 = 0.52. 모두 맞다.
- m ≈ 3D 최적화: mD = n − 1에서 m + 3D의 최소는 2√(3(n − 1)) ≈ 3.46√n. 맞다.
