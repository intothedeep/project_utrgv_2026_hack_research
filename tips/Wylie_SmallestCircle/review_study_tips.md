### B.3 문제 (major)

**M1 (major), 373줄: "2 parallel, 0 meet"의 "아니면" 갈래가 틀렸다.**
- 무엇: "dist(중앙선, L3) ≤ w/2이면 활성 2개. 아니면 2차방정식의 가장 작은 근"이라고 쓴다.
- 왜: dist(M, L3) > h여도 최대 ρ 쌍이 (L_far, L3)이면 활성 2개일 수 있다.
  - 반례는 이 표의 379줄이다. "2 parallel + 수직선 (바깥)"은 PDF의 "2 parallel 0 meet" 그림의 특수 케이스다.
  - 거기서 dist(M, L3) = a > h이지만 답은 r = (a + h)/2이다. 2차식의 근이 아니다.
  - 탐색기 프리셋 "2 평행, 멀리 꼬인 직선"(982)도 ρ_23 = 1.392 > ρ_12 = 1이다.
  - 출처 `02_possible_solutions.md` B절의 주의("일반 dispatcher 판정을 먼저 적용해줘")가 페이지에서 빠졌다.
- 덧붙임: "가장 작은 근"은 "|z|가 가장 작은 근"이어야 한다. q(0) > h²이고 A ≤ 0이기 때문이다.
- 고칠 것: 셀을 "결정 흐름도를 먼저 적용. (L1, L2)가 최대 ρ 쌍이고 활성 3개일 때만 q(z) = h²의 |z| 최소 근"으로 바꾼다.

**M2 (major), 377줄: "1 cross + 수직선: 대칭이 깨짐, 미해결"은 과장이다.**
- 왜: z 반사 대칭은 깨진다. 하지만 180° 회전 대칭이 남는다.
  - 꼬인 두 직선은 공통 수선 중점을 지나는 축에 대한 180° 회전으로 서로 바뀐다. 축은 투영된 X의 이등분선이다.
  - 수직선의 발 S가 그 이등분선 위에 있으면 L3도 제자리로 간다.
  - PDF 그림이 그렇다. 페이지의 프리셋(989)도 그렇다. 회전 (x, y, z) → (−x, y, −z).
  - 볼록성으로 최적 c를 축 위에서 고를 수 있다. 그러면 d1 = d2이고, d1² = d3²는 한 변수 2차식이다.
  - 손 계산 (프리셋 989): d1² = 0.76775·y² + 0.1225, d3² = (y − 1.4)².
  - 근: y = 0.6959, r ≈ 0.704. 쌍 ρ 최대 0.613보다 크므로 활성 3개다.
- 고칠 것: "S가 이등분선 위이면 대칭 축으로 1변수 2차식. 그 밖은 일반 흐름도"로 나눈다. 상태를 "부분 닫힌 해"로 바꾼다.

**M3 (major), 420줄과 706줄: "만남과 접함은 활성 2개 케이스에서 답이 다르다"는 너무 좁다.**
- 왜: 곡선에 접한다는 것은 직선이 원의 접선 방향(n × u_i)을 따른다는 뜻이다. 그러려면 직선이 원의 평면 안에 있어야 한다.
  - 활성 3개 해도 대부분 이 조건을 만족하지 않는다.
  - 그림 1 hyper: 직선 방향 (−sin, cos, 1)이 원의 평면 z = 0 밖으로 나간다.
  - 예각 프리즘: 직선이 원의 평면에 수직이다. 원을 관통하고 접하지 않는다.
  - 활성 3개 해가 접함 해석에서도 성립하는 경우는 공면 삼각형뿐이다.
- 고칠 것: "접함 해석이면 공면 삼각형을 뺀 거의 모든 케이스에서 답이 달라진다. 직선이 구에 접할 뿐 원에 접하지 않는다"로 바꾼다.

### M2 손 유도 (재계산, 검토자와 비교)

프리셋 "1 cross + 수직선": L1 = (0, 0, .35) + t(1, .55, 0), L2 = (0, 0, −.35) + t(−1, .55, 0), L3 = x = 0, y = 1.4인 수직선.

1. 회전 (x, y, z) -> (−x, y, −z)가 L1과 L2를 서로 바꾸고 L3를 제자리에 둔다.
2. 볼록성으로 최적 c를 축 위 (0, y, 0)에서 고른다.
3. d₁² = \|(0, y, −.35) × (1, .55, 0)\|² / 1.3025 = (y² + .15955625)/1.3025 = .767754 y² + .1225
4. d₃² = (y − 1.4)²
5. d₁² = d₃² -> .232246 y² − 2.8 y + 1.8375 = 0 -> y = (2.8 − 2.47649)/.464491 = 0.6965
6. r = 1.4 − 0.6965 = 0.7035 (d₁ = √.49492 = 0.7035로 확인). 최대 ρ는 ρ13 = 1.2266/2 = 0.613이고 r이 더 크므로 활성 3개.

검토자 값 y = 0.6959는 내 값 0.6965와 끝자리가 다르다. r ≈ 0.704 (내 값 0.7035)는 일치한다. 페이지에는 두 값 모두 반올림에 안전한 "r ≈ 0.70"만 썼다.

### 검토자 제안과 다르게 쓴 곳

- M1: 검토자는 "(L1, L2)가 최대 ρ 쌍이고 활성 3개일 때만 q(z) = h²"를 제안했다. 활성 3개는 세 거리가 같다는 뜻이므로 어느 쌍이 최대 ρ이든 d₁ = d₂에서 x = 0이 나온다. 그래서 "활성 3개로 판정되면 q(z) = h²"로 썼다. "(L1, L2) 한정"은 02 문서에도 없다.
- 탐색기 프리셋의 기본값이 아닌 곳의 숫자(r ≈ 0.70)는 페이지 안 간이 풀이로 확인하지 않았다. 손 유도만 했다.
